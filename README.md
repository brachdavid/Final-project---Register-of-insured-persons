# Závěrečná práce - Evidence pojištěných

Konzolová aplikace pro správu pojištěných osob.

## Popis projektu

Aplikace **Evidence pojištěných** je jednoduchý nástroj pro evidenci pojištěných osob. Umožňuje přidávat nové zákazníky či vyhledávat mezi těmi stávajícími.

## Funkce aplikace

- **Přidání nového pojištěnce** – Možnost zaevidovat nového pojištěnce.
- **Vypsání pojištěnců** – Možnost vytvořit seznam všech dosavadních pojištěnců.
- **Vyhledání pojištěnce** – Možnost vyhledat pojištěnce na základě jména a příjmení.

## Technologie

- **Jazyk**: C# (konzolová aplikace)
- **OOP přístup**: Použití tříd a abstrakce pro modelování pojištěnců
- **Validace vstupů**: Ošetření vstupů uživatele pro zajištění správných hodnot (kontrola správnosti zadaných údajů atp.)
- **Kolekce**: Využití kolekce List k evidenci pojištěnců
